# mobx-view-model-vue

Vue 3.5+ bindings for mobx-view-model.

```sh
pnpm add mobx-view-model mobx-view-model-vue mobx vue
```

Exports `observer`, `withViewModel`, `viewModelProps`, `useCreateViewModel`, `useViewModel`, `OnlyViewModel`, and provider components.

See the [Vue integration guide](https://js2me.github.io/mobx-view-model/vue/integration).
