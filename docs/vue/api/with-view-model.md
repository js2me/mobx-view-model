# `withViewModel`

Uses the same call shape as `mobx-view-model-solid`: `withViewModel(VM, render, config?)`. It creates the model, manages its lifecycle, passes it as `model`, and provides it to descendants. Vue views are automatically wrapped in `observer`.

```ts
import { ViewModelBase } from 'mobx-view-model';
import { withViewModel } from 'mobx-view-model-vue';
import { h } from 'vue';

class UserVM extends ViewModelBase<{ userId: string }> {}

export const User = withViewModel(UserVM, ({ model }) =>
  h('div', model.payload.userId),
);
```

```vue
<template>
  <User :payload="{ userId: '42' }" />
</template>
```

The render function receives the component's props except `payload`, plus `model`. The model's `props` and integration hook receive all props, including `payload`. Changes to the payload update the existing model through `setPayload`.

Native Vue components and compiled `.vue` files can also be passed as the second argument. They declare a `model` prop; `viewModelProps<VM>()` is available for runtime props declarations in `defineComponent`.

## Configuration

| Option | Behavior |
| --- | --- |
| `id` | Stable model ID; otherwise generated by the framework |
| `factory` | Custom model factory |
| `ctx` | Creation context |
| `vmConfig` | Core model configuration |
| `getPayload` | Derives the payload from all props; defaults to `viewModelsConfig.getPayload` |
| `fallback` | Component displayed while an asynchronous mount is pending |
| `anchors` | Additional component anchors for store lookups |
| `vueHook` | Vue setup hook receiving `(allProps, ctx, store)`; counterpart of Solid's `solidHook` |

Fallback precedence is `config.fallback`, `config.vmConfig.fallbackComponent`, then `viewModelsConfig.fallbackComponent`. Rendering uses `config.vmConfig.processRender` or the global `viewModelsConfig.processRender` hook.

## `connect(anchor)`

Returns the connected component and registers another anchor for the same model:

```ts
import { defineComponent, h } from 'vue';
import { ViewModelBase } from 'mobx-view-model';
import { useViewModel, withViewModel } from 'mobx-view-model-vue';

class PageVM extends ViewModelBase {}
const Anchor = defineComponent({ render: () => null });
const Child = defineComponent({
  setup() {
    const byAnchor = useViewModel<PageVM>(Anchor);
    const byComponent = useViewModel(Page);
    return () => h('span', `${byAnchor.id}:${byComponent.id}`);
  },
});

export const Page = withViewModel(PageVM, () => h(Child));
Page.connect(Anchor);
```

Render `Page` under `ViewModelsProvider`. The connected component lookup infers the model type.


There is no curried `withViewModel(VM)(View)` overload, matching the Solid API. Use `withViewModel(VM, View, config)`.
